# 🦴 Knee Osteoarthritis Detection Using Hybrid Deep Learning

## 📌 Overview

Knee Osteoarthritis (OA) is one of the most common joint diseases that affects millions of people worldwide. Early diagnosis is essential to prevent severe joint damage and improve patient care.

This project presents an AI-powered web application that automatically detects the stage of Knee Osteoarthritis from X-ray images using a Hybrid Deep Learning model combining **VGG19** and **Vision Transformer (ViT)**.

The application is developed using **Python**, **Flask**, and **TensorFlow**, providing an easy-to-use interface for uploading X-ray images and obtaining predictions.

---

## 🎯 Objectives

- Detect Knee Osteoarthritis from X-ray images.
- Improve prediction accuracy using Hybrid Deep Learning.
- Provide a simple web interface for users.
- Assist healthcare professionals with AI-based diagnosis.

## 🚀 Features

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Knee-Osteoarthritis-Detection-Using-Hybrid-Deep-Learning.git
```

Go to project directory

```bash
cd Knee-Osteoarthritis-Detection-Using-Hybrid-Deep-Learning
```

Install required libraries

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
